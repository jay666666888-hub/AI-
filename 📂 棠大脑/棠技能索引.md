## 强制检查规则

**接任务第一反应 = 扫本skill，再干活。**

必须检查skill的情形：
- 主人说「能不能」「你帮我」「怎么操作」「为什么」
- 涉及已知工具链：抖音/B站/微博/微信/知乎/小红书/六合/公众号
- 需要配置/安装/调试/自动化

**无效借口**（用了就挨骂）：
- 「任务急」 → skill里有更快路径
- 「简单不需要」 → skill有坑点记录
- 「以前做过」 → 记忆会骗人，skill不会

## 技能存放位置

- **Hermes内置skills**：`~/.hermes/hermes-agent/skills/`
- **用户安装skills**：`~/.hermes/skills/`

---

## Skill调用流程

```
1. 接到任务
2. 扫描本索引，找到对应skill
3. skill_view(name) 加载skill
4. 按skill步骤执行
5. 执行中遇到问题 → 查skill里的pitfalls
```

## 新技能安装

```bash
hermes skills install <skill-name>
# 或直接URL
hermes skills install https://.../SKILL.md
```
