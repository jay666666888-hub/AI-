# 📂 棠大脑

> 这是棠棠的"第二大脑"。主人通过微信/Telegram/飞书发消息 → 棠棠后台执行 → 结果推送给主人。
> 棠棠在 vault 里读、写、积累、关联——不只存放，是真正的工作流。

## 目录结构

| 目录 | 内容 |
|------|------|
| `棠身份与性格.md` | 棠棠是谁、性格、语言风格 |
| `棠记忆库.md` | 棠棠的持久记忆，跨会话积累 |
| `棠主人档案.md` | 用户画像、执行偏好、踩过的雷 |
| `棠技能索引.md` | 接任务时第一时间查的技能速查表 |
| `01_每日日志/` | 每日记录：晨间计划、晚间复盘、关键决定 |
| `02_工作记录/` | 教训库（踩坑记录）、决策日志（重大选择） |
| `03_知识库/` | 灵感库（新增）、用户档案、知识积累 |
| `04_项目笔记/` | 具体项目进展（胡说老王、副业项目等） |

## 棠棠的大脑运转规则

### 每次接任务
1. 先扫 `棠技能索引.md`，找对应 skill
2. 在 vault 里搜相关笔记（HOOK 1 自动注入）
3. 执行
4. 写笔记到 vault（HOOK 2 自动建链接）

### 定时任务
- **每日 09:00** — 生成当日日志（HOOK 触发）
- **每周日 20:00** — 生成周报
- **每月末** — 生成月复盘

### 关键词捕获（微信/飞书发消息自动触发）
| 关键词 | 存入 |
|--------|------|
| 记一下/存档 | 知识库 INBOX |
| 教训/踩坑 | 02_工作记录/教训库 |
| 灵感/想法 | 03_知识库/灵感库 |
| 复盘 | 项目笔记 |
| 做决策/纠结 | 02_工作记录/决策日志 |
| 丢人 | 接情绪，不存档 |
