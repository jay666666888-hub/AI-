## 赛道A：养生美食赛道

### 核心数据（来自真实案例）
- **万阅读单价**：300元（是娱乐类的5~10倍）
- **案例**：一篇阅读37,006 → 日收益679元
- **创作时间**：10~15分钟/篇
- **字数要求**：200~300字（短文）

### 为什么适合你
- 创作门槛极低：不需要专业背景，是"生活妙招分享者"
- 素材来源：网络/书籍有大量前人经验，直接改写
- 精准用户：中老年群体爱点赞收藏转发，自带流量
- AI辅助：棠棠用提示词模板批量生成初稿

### 写作结构（固定模板）

**标题公式：**
```
公式1：常见困扰 + 简易方法 + 真实体验
  示例：夜里总醒睡不踏实？老妈教我用两片它泡水，一觉睡到天亮

公式2：打破常识 + 巧妙搭配 + 惊喜效果
  示例：西瓜皮别再随手扔了！和它一起煮水，助眠效果比想象中好
```

**正文模板（棠棠AI指令）：**
```
请你以生活妙招公众号小编的身份，用亲切聊天的语气写一篇200字左右的短文。

结构：
1. 开头提一个很多人都有的小烦恼（比如早上脸部浮肿）
2. 用第一人称说我也遇到过，后来用简单方法改善了
3. 用"大家都知道【食材A】不错，搭配上【食材B】，居然能【效果】"句式
4. 一两句话讲清具体做法

食材示例（棠棠可替换）：
- 生姜+陈皮 → 肠胃舒适、去除湿气
- 红枣+桂圆 → 补气血、助睡眠
- 山楂+枸杞 → 降血脂、护肝
- 花椒+生姜 → 祛湿、暖宫

⚠️ 注意：只讲感受，不提治疗效果
```

### 具体操作步骤

```
Day 1~2：
  1. 注册公众号（名字示例：「养生厨房」「食疗妙招」「健康生活记」）
  2. 棠棠生成5篇养生文章 + 5张配图
  3. 主人发布

Day 3~7：
  每天棠棠生成3篇 → 主人发布
  观察数据：哪类选题阅读量最高

Day 7：
  验收：单篇阅读是否>200
  ↓
  是 → 继续这个食材方向
  否 → 换食材/换话题
```

## 赛道B：副业干货赛道（棠棠首选推荐）

### 核心数据（来自真实案例）
- **收益参考**：日入100~500（稳定后）
- **案例1**：单号年收益37万（纯素人）
- **案例2**：22篇文章引流500人私域，一周变现5000元
- **案例3**：日入2900（新号布局半年）
- **创作时间**：20~30分钟/篇
- **字数要求**：1000~2000字

### 为什么适合你（你有TK经验）
- 你懂投流、人群定向、变现路径 → 这是差异化竞争力
- 你有创业失败经历 → 真实踩坑素材，共鸣感强
- TK经验可以包装成"海外投流教程" → 别人没写过
- 目标读者精准：想赚钱的人天然愿意转发

### 内容方向（4个角度）

```
方向1：TK/跨境投流经验
  - "我在海外投广告踩过的坑，比你想象的多"
  - "TK投流入门：一个人怎么做海外引粉"
  - "海外投流 vs 国内投流：真实对比"

方向2：闲鱼/电商实战
  - "用投流经验做闲鱼，我发现什么"
  - "闲鱼无货源：月入过万的真实与谎言"
  - "一个人怎么做闲鱼：从选品到出单"

方向3：创业踩坑/认知
  - "创业失败后，我用副业还清了负债"
  - "30岁创业失败，我学到了什么"
  - "从0开始做副业：我用3个月试了这些坑"

方向4：副业思维/认知升级
  - "副业最重要的不是赚钱，是……"
  - "为什么你做的副业都不赚钱"
  - "一个方法，帮你找到最适合的副业"
```

### 文章结构模板

```
【标题】：具体痛点/数字/对比

【开头】（150字）：
  [真实经历/痛点场景]
  示例如："3个月前，我拿着借来的5万块钱开始创业。
  3个月后，我亏光了所有钱，还欠了3万。"

【正文】：
  第一点：[核心观点 + 具体案例/数据]
  第二点：[操作步骤 + 细节清单]
  第三点：[认知升级 + 行动建议]

【结尾】：
  [一句金句] + "评论区聊聊你的经历"
  #副业 #赚钱 #创业 #女性成长
```

### 具体操作步骤

```
Day 1~3：
  1. 注册公众号（名字示例：「创业者手记」「副业研究所」「TK投流经」）
  2. 棠棠生成首批内容（主人提供素材方向）
  3. 棠棠生成封面图（统一风格）

Day 4~14（养号期）：
  每天1篇干货文章
  注意：内容要"真实"，不要纯理论

Day 15~30：
  每天1篇 + 开始积累粉丝
  观察：哪些选题数据最好 → 加大这类内容比例
```

## 赛道C：AI+公众号（最新赛道）

### 核心数据（来自真实案例）
- **收益参考**：日入300~1000

### 为什么适合你
- 棠棠就是AI → 棠棠可以批量生成高质量初稿
- 现在是红利期：平台对AI内容识别还不严格
- 可批量操作：棠棠生成 → 主人润色 → 发布
- 可多账号：同一套提示词，生成不同角度内容

### AI创作提示词模板

```
主提示词（发给棠棠）：
  "请以[赛道]公众号作者的身份，帮我写一篇[数字]字的文章。
   主题：[主题]
   风格：[亲切/专业/幽默]
   结构：[痛点开头 + 3个要点 + 总结金句]
   目标读者：[具体人群]

  要求：
  - 开头要有真实感（"我曾经……"或"前几天……"）
  - 中间要有具体步骤或数据
  - 结尾要有互动引导
  - 不要太官方，要有网感"
```

### 具体操作步骤

```
Day 1~2：
  1. 注册公众号（名字示例：「AI副业圈」「AI搞钱笔记」）
  2. 棠棠生成10篇AI辅助文章
  3. 主人润色（改开头/加个人经历/换标题）

Day 3~7：
  棠棠每天生成5篇
  主人每天发布1~2篇
  测试哪类内容数据好

Day 8~14：
  确定最优提示词模板
  棠棠批量生成 → 主人批量润色 → 批量发布
```

## 赛道D：厚黑情感/中老年赛道

### 核心数据（来自真实案例）
- **收益特点**：中老年用户互动率高，留言区广告触发率高
- **案例**：单篇阅读10万+，留言区广告收益可观
- **创作时间**：5~10分钟/篇（纯AI批量）
- **字数要求**：300~500字（短文）

### 为什么适合你
- 竞争少：这个赛道做的人少
- 复利强：中老年爱收藏、转发，历史文章持续推流
- 棠棠可批量生成：3段文案+3张配图，全自动
- 生命周期长：选题可循环使用

### 内容方向

```
方向1：厚黑学/处世之道
  - "这3种人，最不值得你付出真心"
  - "老实人为什么总是吃亏？"
  - "人在职场，这3句话烂在肚子里也不能说"

方向2：情感鸡汤
  - "婚姻里，最伤人的不是出轨，而是……"
  - "婆媳关系：聪明女人都这样做"
  - "人到中年，才会明白这3件事"

方向3：人情世故
  - "送礼的学问：这三样东西千万不能送"
  - "饭局潜规则：你真的懂怎么敬酒吗"
  - "为什么你帮了人，反而被记恨？"
```

### 创作模板

```
标题：[场景] + [金句/反转]

01 [小标题]
[80~100字：一个贴近生活的故事或观点，短句，大白话]

02 [小标题]
[80~100字：第二个观点或故事]

03 [小标题]
[80~100字：总结+给读者的建议]

配图：棠棠AI生成温馨手绘风插图（每篇3张）
```

## 赛道F：小众冷门赛道

### 核心数据（来自真实案例）
- **收益参考**：日入400~1000
- **特点**：知道的人少，竞争小，容易出爆款
- **案例**：知乎神回复搬运 → 日入400

### 具体操作

```
操作：搬运知乎高赞回答/神回复
优势：内容本身已经过验证（高赞=有共鸣）
风险：可能有版权问题，建议AI改写后再发

步骤：
1. 棠棠抓取知乎高赞回答（点赞>1000的）
2. 棠棠用AI改写成公众号风格
3. 主人发布

变现：流量主 + 评论区引导（"同意的点个赞"）
```

### 适合的小众方向

```
1. 知乎神回复/神评论搬运（已验证的共鸣内容）
2. 冷门历史/冷知识（"历史课本不会告诉你的事"）
3. 民间智慧/俗语解读（"老话说的好……"）
4. 行业揭秘（某个少有人知的行业真相）
```
