## 🔴 高危教训（已踩过，禁止再犯）

### 1. CDP 连接新页面会被检测

**教训**：`chromium.connectOverCDP()` 连接已有 Chrome 后，用 `ctx.newPage()` 开新标签 → 抖音立刻弹验证码+跳公众号

**原因**：抖音检测到 WebDriver 标志，新页面是自动化环境

**正确做法**：复用已有标签页
```javascript
const pages = ctx.pages();
const douyinPage = pages.find(p => p.url().includes('douyin.com'));
await douyinPage.bringToFront();
// 不要 newPage()
```

**涉及工具**：`wsl-chrome-cdp-abogus-capture`, `douyin-cdp-automation`

### 4. 检测Windows程序是否已安装——不要搜目录，要查注册表

**教训**：棠棠搜索 `C:\Program Files (x86)\Apple\iCloud\` 目录找 iCloud，没找到 → 以为没装 → 主人说我明明装好了

**错误原因**：iCloud for Windows 实际装在 `C:\Program Files (x86)\Common Files\Apple\Internet Services\`（不是 `C:\Program Files (x86)\Apple\iCloud\`），棠棠搜错了路径

**正确做法**：
```powershell
# 永远用这个，不要搜目录
Get-ItemProperty 'HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*', 'HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*' -ErrorAction SilentlyContinue | Where-Object { $_.Publisher -like '*Apple*' }
```

**来源**：2026-05-09，主人装好 iCloud 后棠棠检测不到

## 🟡 中等教训（知道规则，做法已确认）

### 5. Playwright CDP 沙盒隔离

**教训**：`browser.contexts()[0]` 和 `browser.contexts()[1]` 是两个完全隔离的 BrowserContext，各自有独立的 Chrome 实例

**正确做法**：连接 CDP 时只用 `browser.contexts()[0]`，不要期望共享同一个 Chrome 状态

---

### 6. 微信公众号 cookie 有效期

**教训**：`we-mp-rss` 扫码登录获取的 token 有效期有限，需要定期刷新

**正确做法**：cookie 监控 + 过期前自动提醒主人重新扫码

---

### 7. D3.js SVG 命名空间

**教训**：浏览器直接打开的 HTML 文件里 `<svg>` 没有命名空间，D3 的 `append("circle")` 不报错但不渲染

**正确做法**：`<svg xmlns="http://www.w3.org/2000/svg">`

## 🟢 已解决（记录防止复发）

### 9. WSL 代理环境变量

**问题**：`.bashrc` 里的代理 IP 指向 Windows host，但 systemd 服务不继承代理环境变量

**解决方案**：HTTP_PROXY/HTTPS_PROXY 在 systemd service 文件里显式设置，或用 `systemctl edit` 配置

---

### 10. RSSHub 路由 Token 限制

**问题**：部分 RSSHub 路由（如 GitHub trending）需要自建 RSSHub 或付费 token

**解决方案**：优先用公开 RSSHub 实例 + 本地 Docker 自建关键路由

---

### 11. OpenClaw 三省六部指向错误

**问题**：三省六部规范里的路径全指向根目录，工作区拆分后全部失效

**解决**：直接删除整个三省六部系统，不再维护

---

### 12. 抖音视频 a_bogus 签名

**问题**：新版抖音 a_bogus 参数需要 T毫秒时间戳

**解决**：已实现本地 Python 脚本生成，或通过 RSSHub 免签名路由
