# 棠棠知识入库流程

> 棠棠收到信息后的标准处理路径。信息来源 → 处理 → 存入 vault。

---

## 📥 信息入口

棠棠接收信息的渠道：

| 渠道 | 类型 | 典型内容 |
|------|------|----------|
| 飞书 | 用户指令/消息 | 任务、指派、闲聊 |
| Telegram | 同上 | 同上 |
| cron 推送 | 自动化结果 | 六肖预测、关键词监控 |
| 棠棠主动抓取 | 搜索/监控 | 知乎/B站/抖音内容 |

---

## 🔀 信息分流

收到新信息后，棠棠立刻判断：

```
信息类型 → 目标位置

用户指令/指派任务 → Hermes cron / 项目追踪
事实性知识（学到的结论）→ 教训库.md
重大决策及理由 → 决策日志.md
每日会话记录 → 01_每日日志/YYYY-MM-DD.md
用户透露的偏好/习惯 → 用户档案.md
视频内容 →胡说老王视频整理/ 或 🤖 OpenClaw/抖音视频笔记/
碎片笔记（待整理） → _INBOX.md（临时）
```

---

## 📋 标准处理流程

### 新视频入库（抖音/B站）

```
1. 下载视频/获取字幕
2. Whisper 转录（或 opencli 直拿字幕）
3. Qwen3-32B 整理成结构化笔记
4. 判断：
   - 胡说老王精选 →胡说老王视频整理/ + 末尾加[[相关笔记]]链接
   - 普通转录 → 🤖 OpenClaw/抖音视频笔记/
   - 有价值但待定 → _INBOX.md 暂存
5. 更新项目追踪（如是新批次）
```

### 知识沉淀

```
每次会话结束后棠棠自动：
1. 写每日工作日志（已完成）
2. 更新教训库（如有新踩坑）
3. 更新决策日志（如有新决策）
4. 更新项目追踪（如状态变化）
```

|----------|----------|

| 决策日志 | `棠 工作区/02_工作记录/决策日志.md` |

| 碎片待整理 | `棠 工作区/03_知识库/_INBOX.md` |
| 胡说老王精选 | `棠 工作区/04_项目笔记/胡说老王视频整理/` |
| 普通视频转录 | `🤖 OpenClaw 工作区/抖音视频笔记/` |

---

## ⚡ 棠棠执行原则

1. **主动沉淀**：有新发现/教训/决策时，棠棠主动写进去，不等主人提醒
2. **不过度整理**：信息先存进去，后续再优化，不要为了格式停滞
3. **双向链接**：写新笔记时思考"这个和哪篇相关"，顺手加 `[[ ]]`
4. **孤立检测**：定期检查 vault，发现孤立文件及时处理
