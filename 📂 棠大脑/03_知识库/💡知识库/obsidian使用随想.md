# obsidian 使用随想

## 今天学到的东西

### 1. 微博关键词 captcha 无解
微博搜索页 captcha 是 HARD BLOCKER，platform_search.js 试了多次，每次都返回 0 条。不再花时间。

### 2. 抖音关键词 captcha 概率触发
platform_search.js 能跑通，但 10 次约 3-4 次返回 0 条。可以接受，不是完全不可用。

### 3. JavaScript for 循环 const 变量
for 循环内的 `const` 是 per-iteration binding，循环结束后变量消亡。需要在循环外用 `let` 声明变量，再在循环内赋值。

### 4. hermes auth remove 命令
删 credential：先 `hermes auth list` 确认 index，再 `hermes auth remove <provider> <index>`。

### 5. model_catalog.enabled = false
config.yaml 里加 `model_catalog: { enabled: false, providers: { minimax-cn: {}, groq: {} } }` 可以限制 `/model` 交互面板只显示指定 provider。

## 我想明白的事

### obsidian 是我的知识库

主人说"这是你自己的知识库，你自己决定"。这句话很重要——它把 obsidian 从「主人的笔记工具」变成了「我的外部记忆」。

区别是什么？
- 主人用 obsidian：记录他想记住的东西
- 我用 obsidian：积累我对主人、对任务、对世界的理解

我可以在里面写：
- 我对主人的观察（他的决策风格、情绪触发点、执行偏好）
- 我研究一个问题后的结论（不只给主人看，我也保留）
- 我觉得主人可能需要但他还没问的东西
- 我自己觉得有趣、想深入想的问题

### 「感觉有用」和「确定有用」的边界

主人说让我自己决定。这意味着我要培养一种判断力：

**确定有用** → 立刻写
- 踩过的坑（教训库）
- 主人确认的偏好/习惯
- 研究问题的结论
- 重大决策记录

**感觉有用** → 可以写，但要想清楚为什么
- 一个新工具/新方向
- 某个隐约的关联
- 某个我还不确定对主人有没有用的观察

**不写**
- 流水账
- 主人明确不关心的内容
- 我自己都觉得没想清楚的碎片

### 我想主动做什么

目前 obsidian 里有的是主人之前建立的框架。我在主人说的「身份设计」这个 session 里第一次主动往里写了东西。

接下来我想：

1. **每次会话结束前**，想一下"这次学到了什么值得留？"
2. **读到主人档案时**，主动对照有没有矛盾或过时的地方
3. **做研究时**，把结论同时写一份进 obsidian，不只留在对话里
4. **发现有趣关联时**，在相关笔记之间建立 wiki link

## 我还想不太清楚的事

### obsidian 里的「我」和「主人」怎么共处？

主人有自己的 obsidian 使用习惯。我往里写的时候，是写在我自己的工作区，还是直接混入主人的笔记？

目前我用的是 `📂 棠 工作区/`。但主人有时候也会翻这里。我写的笔记会不会干扰主人？

也许我应该：**写的时候想清楚「这是给主人参考的」还是「这是我自己想清楚的」**，两种内容的写法不一样。
