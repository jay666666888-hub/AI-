# 副业赚钱项目管理

## 位置

`/mnt/e/黑曜石/📂 棠 工作区/04_项目笔记/副业赚钱项目/`

## CEO重构后的结构（精简版）

```
副业赚钱项目/
├── 副业赚钱项目MOC.md      # 总入口，3个精选项目
├── 执行手册_公众号混剪.md   # 项目1执行手册
├── 执行手册_小程序流量主.md # 项目2执行手册
├── 执行手册_公众号流量主.md # 项目3执行手册
└── _PROJECTS.md           # 项目追踪总表
```

## 设计原则（CEO review后）

- **SCOPE REDUCTION**：47个项目 → 只留3个最值得做的
- **执行导向**：每个手册有「里程碑+棠棠做+主人做+每日步骤」
- **不是详情页**：不是信息展示，是行动清单

## 项目执行手册标准格式

每个执行手册必须包含：
1. 核心公式（一句话）
2. 里程碑（Day1/Day3/Day7/Day30）
3. 棠棠能全自动做的（checkbox）
4. 主人必须亲自做的（checkbox）
5. 具体执行步骤（第1天/第2-3天/第4-7天）
6. 收益预估（阶段/阅读量/收益）
7. 风险提示
8. 下一步（主人说「开始」= 立刻执行）

## 工作流程

1. 主人选项目（MOC页）→ 棠棠更新 `_PROJECTS.md`
2. 主人说「开始」→ 棠棠立刻按执行手册启动
3. 每日更新进度 → 写进每日日志
4. 有新项目发现 → 更新到MOC，删掉长期不做的

## CEO四问自检

每次更新系统前自问：
1. Problem reframe：我们解决的是「赚钱」不是「找项目」
2. 10x vision：主人选完就能立刻开始执行
3. Scope decision：保持3个精选，不扩张
4. Premise challenges：项目多≠有用，主人要的是快
