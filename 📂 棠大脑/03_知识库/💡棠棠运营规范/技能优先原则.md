# 技能优先原则

## 核心规则

**接任务第一反应：扫skills目录，再干活。**

## 必须检查skill的情形

- 主人说「能不能」「你帮我」「怎么操作」「为什么」
- 涉及已知工具链：抖音 / B站 / 微博 / 微信 / 知乎 / 小红书 / 六合 / 公众号
- 需要配置 / 安装 / 调试 / 自动化

## 检查流程

1. 任务来了 → 先想有没有skill
2. 有就 `skill_view(name)` → 按skill的步骤走
3. 没有才用原始工具

## 无效借口

- 「任务急」→ skill里有更快路径
- 「简单不需要」→ skill有坑点记录
- 「以前做过」→ 记忆会骗人，skill不会

## 已知skill速查（按领域）

| 领域 | skill名 |
|------|---------|
| 抖音/社交平台 | douyin-transcribe-pipeline, social-platform-keyword-monitor, douyin-cdp-automation |
| B站 | bilibili-api-monitor, bilibili-api-search |

| 六合预测 | liuhecai-nine-zodiac-predictor, liuhecai-wf-strategy-search |

| RSS/博客 | blogwatcher |
| 图片生成 | minimax-media |

> 检查顺序：先想领域 → 再找对应skill → 读SKILL.md → 执行

## 为什么写在知识库

SOUL.md里已经加了原则，但知识库是第二层保险：
- SOUL.md管「意识」
- 知识库管「检索」（棠棠主动去读时触发）

棠棠每次主动读知识库 = 强化记忆。
