## 使用流程

1. 主人说「找副业项目」→ 棠棠搜索 → 更新到Obsidian
2. 主人选择项目 → 棠棠在对应详情页填执行步骤
3. 启动 → 状态改为「#执行中」

## 搜索命令

```bash
node /home/admin1/platform_search.js '["副业 赚钱 项目 2026"]'
```

## 项目详情页模板


状态标记：`#未启动` / `#候选` / `#已启动` / `#执行中` / `#已完成`

## 棠棠的职责

- 每次发现新项目 → 写入Obsidian
- 主人选项目 → 棠棠立刻拆执行步骤
- 定期更新项目状态
