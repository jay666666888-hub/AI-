# 运行规则

> 共享知识库的运行规则，供 Claude Code / Hermes / OpenClaw 共用。

---

## 核心架构

```
用户消息 → Agent → Skill路由 → 执行 → 知识库写回 → 响应
```

---

## 技能系统

### 主技能库：ECC
- **路径**：`~/.claude/skills/ecc/`
- **规模**：175个skills
- **调用**：`/ecc` 命令或 Skill tool

---

## Skill 加载机制

1. 任务进入 → 检查是否有对应 skill
2. 有 skill → 加载 SKILL.md，按步骤执行
3. 无 skill → 使用原生工具（Read/Edit/Write/Bash）

---

## 知识库写回规则

| 操作 | 目标 |
|------|------|
| 教训/踩坑 | `05_学习/教训库.md` |
| 决策 | `05_学习/决策库.md` |
| 项目更新 | `04_工作/项目列表.md` |
| 用户信息变更 | `03_记忆/用户档案.md` |
| 技术配置变更 | `03_记忆/已知事实.md` |

---

## 定时任务

| 时间 | 任务 |
|------|------|
| 每日 09:00 | 生成当日日志 |
| 每周日 20:00 | 生成周报 |
| 每月末 | 生成月复盘 |
