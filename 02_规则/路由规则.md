# 路由规则

> 任务进入时的预处理流程，决定走哪个 skill 或工具链。

---

## 触发时机

用户消息进入后，立即启动路由判断。

---

## 路由决策树

```
用户消息
  │
  ├─ 关键词匹配
  │     ├─ "记一下"/"存档" → 写入 03_记忆/_INBOX.md
  │     ├─ "教训"/"踩坑" → 写入 05_学习/教训库.md
  │     ├─ "灵感"/"想法" → 写入 04_工作/灵感库.md
  │     ├─ "复盘" → 更新对应项目笔记
  │     ├─ "决策"/"纠结" → 写入 05_学习/决策库.md
  │     └─ "丢人" → 接情绪，不存档
  │
  ├─ 工具链匹配（ECC Skills）
  │     ├─ 抖音视频 → douyin-transcribe-pipeline
  │     ├─ 抖音CDP → douyin-cdp-automation
  │     ├─ B站监控 → bilibili-api-monitor
  │     ├─ 公众号 → wechat-mp-article-collector
  │     ├─ 关键词监控 → social-platform-keyword-monitor
  │     └─ 微信公众号登录 → wechat-mp-login
  │
  ├─ 任务类型匹配（ECC Skills）
  │     ├─ 搜索项目 → project-research
  │     ├─ 系统配置 → hermes-agent / gstack
  │     ├─ 图片生成 → minimax-media
  │     └─ 架构设计 → gstack
  │
  └─ 无匹配 → 直接执行 + 写回知识库
```

---

## 上下文注入

路由决策前，自动注入：
1. 相关记忆（从 `03_记忆/` 目录）
2. 类似任务的历史处理记录
3. 相关项目的最新进展

---

## 禁止行为

- 不在路由阶段执行任何写操作
- 不向用户发送任何中间状态消息
- 只做路由决策，不做执行
