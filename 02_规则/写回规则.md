# 写回规则

> 任务完成后自动将结果写入共享知识库。

---

## 触发条件

满足以下任一条件时触发写回：
1. 任务执行完成（有明确结果）
2. 关键决策点（需要记录选择）
3. 错误发生（需要记录教训）
4. 用户明确要求"记一下"

---

## 写回位置规则

| 结果类型 | 写入位置 |
|---------|---------|
| 任务结果 | 对应项目笔记（`04_工作/`） |
| 踩坑记录 | `05_学习/教训库.md` |
| 灵感想法 | `04_工作/灵感库.md` |
| 重大决策 | `05_学习/决策库.md` |
| 报错解决 | `05_学习/教训库.md` |
| 临时内容 | `03_记忆/_INBOX.md` |
| 技术配置变更 | `03_记忆/已知事实.md` |
| 用户信息变更 | `03_记忆/用户档案.md` |

---

## 链接建立

每次写回时，自动建立双向链接：
```markdown
---
related::
← [[源文件.md]]
← [[00_Index.md]]
← [[2026-05-13.md]]
→ [[目标文件.md]]
---
```

---

## 自动索引更新

- `04_工作/项目列表.md` — 新项目自动加入
- `05_学习/教训库.md` — 教训自动追加
- `05_学习/决策库.md` — 决策自动追加

---

## 禁止行为

- 不覆盖已有内容（只追加）
- 不删除用户文件
