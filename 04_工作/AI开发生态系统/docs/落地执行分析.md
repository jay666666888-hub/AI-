## 二、核心问题诊断

### 2.1 Ralph 循环是"假循环"

**症状**: `_run_skill_stage()` 调用 skill 返回的是 instruction dict，不是真正的执行结果

```python
# 当前问题代码 (ralph_loop_task.py:264-295)
def _run_skill_stage(self, skill_name: str, input_data) -> dict:
    if skill_name == "brainstorming":
        result = self.orchestrator.skills[skill_name].run(input_data)
        # 返回的是 {"instruction": "...", "guidance": [...]}
        # 而不是真正执行任务的结果
```

**影响**:
- Stage 1: brainstorming 只返回"如何做"的指导，不执行
- Stage 2: tdd 跳过测试编写
- Stage 3: build 跳过代码创建
- Stage 4-6: review/verification/e2e 都是返回指导

**根因**: Skills 设计为"指导模式"而非"执行模式"

## 三、落地执行方案（100% 成功率）

### 阶段一：修复核心循环 (第1天)

#### 1.1 将 Skills 从"指导模式"转为"执行模式"

**方案**: 新增 `SkillExecutor` 类，真正执行 skill 返回的 instruction

```python
# skill_executor.py - 新增
class SkillExecutor:
    """将 instruction 转为真正的执行"""

    def execute(self, skill_name: str, instruction: dict) -> dict:
        """根据 skill 返回的 instruction 执行"""
        if skill_name == "brainstorming":
            return self._execute_brainstorming(instruction)
        elif skill_name == "tdd":
            return self._execute_tdd(instruction)
        # ...
```

#### 1.2 修改 ralph_loop_task.py

```python
# 关键修改
def _run_skill_stage(self, skill_name: str, input_data) -> dict:
    skill = self.orchestrator.skills[skill_name]
    instruction = skill.run(input_data)

    # 新增: 执行 instruction
    executor = SkillExecutor()
    result = executor.execute(skill_name, instruction)

    return result
```
