# 六肖预测系统规格

## 1. 目标

基于历史开奖数据（500期），预测下一期特码生肖（12选1）。

## 2. 数据结构

```python
# 输入数据 (liuhecai_data.json)
{
  "期号": "2026135",
  "开奖时间": "2025-01-02 21:32:32",
  "特码号码": "22",
  "特码生肖": "羊",           # 目标变量
  "波色": "green",
  "开奖号码": ["25", "18", "06", "14", "29", "39", "22"],
  "开奖生肖": ["龍", "豬", "豬", "兔", "鼠", "虎", "羊"],
  "波色列表": ["blue", "red", "green", "blue", "red", "green", "green"]
}
```

## 3. 特征工程

| 特征名 | 描述 | 计算窗口 |
|--------|------|----------|
| gap | 距上次出现的遗漏期数 | 全历史 |
| recent3/5/10/20/30 | 近N期出现次数 | N |
| streak | 连续出现次数 | 当前 |
| freq_12 | 12期频率 | 12 |
| freq_30 | 30期频率 | 30 |
| rev_ratio | 短期vs长期频率比 | 3 vs 12 |

## 4. 预测算法

**贝叶斯排名法**:
1. 计算每个生肖的多个特征
2. 将特征值转为排名（0-11）
3. 加权求和得到综合分数
4. 选择分数最高的6肖

**权重配置**:
```python
WEIGHTS = {
    'gap': 2.5,        # 遗漏越大排名越前
    'recent3': 1.0,    # 近期活跃度
    'recent5': 1.5,
    'recent10': 1.5,
    'recent20': 0.0,   # 不使用
    'recent30': 1.0,
    'streak': 0.3,     # 连出加成
}
```

## 5. 验证流程

1. **回测**: 用前N期数据预测第N+1期，计算命中率
2. **延迟验证**: 用 delayed_outcome_tracker 验证预测结果
3. **ECE校准**: 用统一校准系统跟踪预测准确率

## 6. 输出格式

```json
{
  "predict_period": "2026136",
  "top6": ["龍", "雞", "豬", "虎", "蛇", "鼠"],
  "scores": {"龍": 72.3, "雞": 58.9, ...},
  "confidence": 0.85,
  "n_train": 500,
  "features": {...}
}
```

## 7. 评估指标

- 命中率 (6肖中1 = 命中)
- ECE (Expected Calibration Error)
- 延迟失败率 (预测成功但实际失败)
