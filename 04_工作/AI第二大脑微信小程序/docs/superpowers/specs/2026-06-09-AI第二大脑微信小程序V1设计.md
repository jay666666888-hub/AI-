# AI第二大脑微信小程序 V1 设计规格

> 创建时间: 2026-06-09
> 状态: 已批准

---

## 1. 产品定位

**定位**: 项目管理 + 任务管理 + 记录系统 + 长期记忆

**非定位**: 不是待办清单，不是备忘录，不是日历

**核心目标**: 让用户把所有事情、想法、计划、项目统一管理

**AI策略**: AI功能预留接口，V1不开发AI聊天页面

---

## 2. 技术架构

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | 微信原生开发 | 微信小程序 |
| 后端 | Python + FastAPI | 复用现有Python技术栈 |
| 数据库 | PostgreSQL | 现有云服务器 |
| 用户认证 | 微信登录 | V1只有微信登录，账号密码登录V2再说 |
| 消息推送 | 微信订阅消息 | 预留WebSocket方案 |
| 部署 | 现有云服务器 | 复用现有资源 |

## 3. 数据库设计

### 3.1 设计原则

1. **AI统一字段**: 所有实体使用 `ai_metadata JSONB` 预留AI字段，未来AI功能无需改表结构
2. **软删除**: 使用 `deleted_at` 字段，支持数据恢复
3. **统一任务表**: 所有任务类型统一到 `tasks` 表，通过 `type` 字段区分
4. **通用附件**: `attachments` 表通过 `entity_type/entity_id` 支持所有实体

### 3.2 表结构

#### users - 用户表
```sql
CREATE TABLE users (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  wx_openid       VARCHAR(100) UNIQUE,
  wx_unionid      VARCHAR(100) UNIQUE,
  nickname        VARCHAR(100),
  avatar_url      VARCHAR(500),
  phone           VARCHAR(20),
  ai_metadata     JSONB,
  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW(),
  deleted_at      TIMESTAMP
);
```

#### projects - 项目表
```sql
CREATE TABLE projects (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES users(id),
  title           VARCHAR(200) NOT NULL,
  description     TEXT,
  goal            TEXT,
  status          VARCHAR(20) DEFAULT 'active',  -- active/archived/completed
  progress INT DEFAULT 0,                   -- 0-100
  tags TEXT[],
  ai_metadata     JSONB,
  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW(),
  deleted_at      TIMESTAMP
);
```

#### tasks - 统一任务表
```sql
CREATE TABLE tasks (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES users(id),
  project_id      UUID REFERENCES projects(id),

  type            VARCHAR(20) NOT NULL,  -- todo/habit/schedule/waiting/checklist
  title           VARCHAR(200) NOT NULL,
  detail          TEXT,
  detail_source   VARCHAR(20),           -- manual/ai_generated/ai_rewritten
  status          VARCHAR(20) DEFAULT 'active',  -- active/completed/cancelled/archived

  due_date        TIMESTAMP,
  priority        INT DEFAULT 3,          -- 1-5
  tags            TEXT[],
  ai_metadata     JSONB,

  -- Habit 特有
  frequency       VARCHAR(20),            -- daily/weekly/monthly/custom
  execution_mode  VARCHAR(20),            -- timed/free
  scheduled_time VARCHAR(10), -- 21:00
  target_type    VARCHAR(20),            -- count/duration/custom
  target_value   INT,                     -- 如: 30(分钟/次/页)

  -- Schedule 特有
  location       VARCHAR(200),
  start_time     TIMESTAMP,
  end_time       TIMESTAMP,

  -- Waiting 特有
  wait_status    VARCHAR(20),            -- waiting/recovered

  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW(),
  deleted_at      TIMESTAMP
);
```

#### habit_logs - Habit执行记录
```sql
CREATE TABLE habit_logs (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  task_id         UUID REFERENCES tasks(id),
  executed_at     TIMESTAMP DEFAULT NOW(),
  status          VARCHAR(20) DEFAULT 'completed',  -- completed/partial/missed/makeup
  ai_metadata     JSONB
);
```

#### checklist_items - 清单子项
```sql
CREATE TABLE checklist_items (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  task_id         UUID REFERENCES tasks(id),
  parent_id       UUID REFERENCES checklist_items(id),  -- 仅一级parent
  content         VARCHAR(500) NOT NULL,
  is_done         BOOLEAN DEFAULT FALSE,
  sort_order      INT DEFAULT 0,
  ai_metadata     JSONB,
  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW()
);
```

#### notes - 快速记录
```sql
CREATE TABLE notes (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES users(id),
  content         TEXT NOT NULL,
  status         VARCHAR(20) DEFAULT 'inbox',  -- inbox/processed/archived
  tags            TEXT[],
  ai_metadata     JSONB,
  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW(),
  deleted_at      TIMESTAMP
);
```

#### memories - 长期记忆
```sql
CREATE TABLE memories (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES users(id),
  title           VARCHAR(200) NOT NULL,
  content         TEXT,
  tags            TEXT[],
  memory_type     VARCHAR(20),  -- personal/family/project/important
  ai_metadata     JSONB,
  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW(),
  deleted_at      TIMESTAMP
);
```

#### reminders - 统一提醒表
```sql
CREATE TABLE reminders (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES users(id),
  entity_type     VARCHAR(20),            -- task/habit/schedule/note
  entity_id       UUID,
  remind_at       TIMESTAMP NOT NULL,
  repeat_rule     JSONB,                  -- {"freq": "daily", "time": "21:00"}
  wx_template_id  VARCHAR(100),
  is_sent         BOOLEAN DEFAULT FALSE,
  ai_metadata     JSONB,
  created_at      TIMESTAMP DEFAULT NOW(),
  sent_at         TIMESTAMP
);
```

#### attachments - 通用附件表
```sql
CREATE TABLE attachments (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  entity_type     VARCHAR(20),            -- project/task/note/memory/log
  entity_id       UUID,
  url             VARCHAR(500) NOT NULL,
  file_type       VARCHAR(50),
  file_name       VARCHAR(200),
  ai_metadata     JSONB,
  created_at      TIMESTAMP DEFAULT NOW()
);
```

#### project_logs - 项目日志
```sql
CREATE TABLE project_logs (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  project_id      UUID REFERENCES projects(id),
  action         VARCHAR(50) NOT NULL,   -- created_task/completed_task/updated_project...
  content        TEXT,
  ai_metadata     JSONB,
  created_at      TIMESTAMP DEFAULT NOW()
);
```

#### notifications - 通知中心
```sql
CREATE TABLE notifications (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES users(id),
  title           VARCHAR(200) NOT NULL,
  content         TEXT,
  type            VARCHAR(20),   -- reminder/system/project
  entity_type     VARCHAR(20),   -- task/project/note (用于跳转)
  entity_id       UUID,
  is_read         BOOLEAN DEFAULT FALSE,
  created_at      TIMESTAMP DEFAULT NOW()
);
```

## 6. 任务状态流转

### 6.1 统一status字段
- `active` - 激活状态
- `completed` - 已完成
- `cancelled` - 已取消
- `archived` - 已归档

### 6.2 业务状态映射

| type | active时的业务状态 | 转换条件 |
|------|-------------------|---------|
| todo | 进行中 | 完成→completed |
| habit | 进行中 | 执行log→计数 |
| schedule | 待执行 | 时间到期自动更新 |
| waiting | 等待中 | wait_status=recovered→completed |
| checklist | 进行中 | 所有子项完成→completed |

### 6.3 Inbox 流转（Note专属）
```
快速记录 → notes.status='inbox'
整理 → notes.status='processed' 或 转换为 task/project/memory
```

## 9. 任务类型详细设计

### 9.1 Inbox（Note专属，非Task）
- 所有想法、记录、计划默认进入 notes 表
- 通过 `notes.status='inbox'` 实现
- 整理后可转换为: Task / Project / Memory

### 9.2 Todo
- 一次性任务，完成即结束
- 字段: title, detail, due_date, priority

### 9.3 Habit
- 重复执行任务
- 字段: frequency, execution_mode, scheduled_time, target_type, target_value
-统计: 连续天数, 总完成次数, 完成率

### 9.4 Schedule
- 绑定日历的事件
- 字段: title, start_time, end_time, location, reminder

### 9.5 Waiting
- 当前无法推进的事项
- 字段: wait_status (waiting/recovered)

### 9.6 Checklist
- 流程类事项，支持多级子项
- 字段: parent_id(一级自关联)
