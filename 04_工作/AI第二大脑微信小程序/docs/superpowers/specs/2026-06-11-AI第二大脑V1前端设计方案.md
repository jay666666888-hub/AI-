# AI第二大脑 V1 高保真前端设计方案

> **版本**: V1.0
> **日期**: 2026-06-11
> **目标**: 个人长期使用，高效率，重信息密度
> **风格参考**: Things 3 / 滴答清单 / Obsidian / Todoist

---

## 1. 整体导航设计

### 推荐方案：4 Tab 设计

```
┌─────────────────────────────────────────┐
│                 首页 │
│              (Today View)                │
├─────────────────────────────────────────┤
│ 任务                      │
│            (Task Center)                 │
├─────────────────────────────────────────┤
│                 项目                      │
│            (Project List)               │
├─────────────────────────────────────────┤
│                 我的 │
│            (Settings)                    │
└─────────────────────────────────────────┘
```

### 选择原因

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| 首页/任务/项目/我的 | 分工明确，符合任务管理逻辑 | - | **✅ 推荐** |
| 今日/项目/记录/我的 | 强调时间维度 | 个人用户"记录"使用率低 | ❌ |

**推荐理由**：
1. **任务为核心**：Todoist/滴答清单 都以任务为中心
2. **项目为容器**：项目是任务的分组，符合层次结构
3. **我的**：个人使用只需简单设置
4. **跳转少**：4 Tab 覆盖90% 使用场景

        ┌────────────────┼────────────────┐
        ↓                ↓                ↓

   创建任务      创建项目并关联 创建记忆

## 11. 技术实现说明

### 11.1 页面配置

每个页面需要4个文件：
- `index.js` - 逻辑
- `index.wxml` - 结构
- `index.wxss` - 样式
- `index.json` - 配置

使用微信小程序原生 `getApp()` 全局状态：
- `token` - 登录令牌
- `userInfo` - 用户信息
- `baseUrl` - API地址
