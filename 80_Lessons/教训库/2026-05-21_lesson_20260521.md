# Lesson - 2026-05-21

## 内容
这个更新思路是对的，而且已经从“Prompt”升级成“Skill + 数据层 + 模板层”。
我会补几个容易踩坑的点，不然以后会出现“看起来很强，实际乱跑”。
建议补充：
1. 多平台采集增加可信度权重
别让 Hermes 默认各平台权重一样：
小红书：景点/拍照/穿搭 → 权重高
大众点评：餐厅/避坑 → 权重高
携程：酒店/交通 → 权重高
Reddit：真实体验/避坑 → 权重高
抖音：热点参考 → 权重低
YouTube：路线体验 → 中
避免：
抖音爆火 → Hermes直接安排
改成：
多平台交叉验证后再进入候选池
2. Chrome CDP增加失败回退
否则某个平台登录失效就卡死：
采集失败处理：

平台失败：

重试2次

仍失败：

切换：

网页搜索
缓存数据
替代平台

禁止等待单平台
3. 时间衰减规则
旅游内容过期很快：
发布时间：

7天内：100%

30天内：90%

90天内：70%

180天内：40%

>180天：

低可信
例如：
“樱花路线”
去年内容可能完全失效。
4. 加一个旅行成本预测
自动算：
门票
酒店
打车
高铁/机票
吃饭
临时
