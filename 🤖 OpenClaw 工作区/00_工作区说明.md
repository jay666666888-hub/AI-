# 🤖 OpenClaw 工作区

> 这是 OpenClaw/Hermes Agent 系统的"工作区"。
> 所有系统配置、Skills、数据都在这里。
> 主人一般不需要看这个目录。

## 目录结构

| 目录 | 内容 |
|------|------|
| `02_已装Skills` | 所有已安装 Skills 的速查表 |
| `04_规范与流程` | 运营 SOP（多平台采集、视频转录） |
| `✅任务列表` | 任务跟踪总表（无僵尸任务） |
| `📂任务派单` | 任务派单文件 |
| `📂任务结果` | 任务结果文件 |
| `抖音视频笔记` | 抖音视频转录后的 Markdown 笔记 |

## 规范与流程（04_规范与流程）

- `内容采集转录流程.md` — 多平台采集总览（B站/抖音/小红书/微博）
- `抖音数据采集转录流程.md` — 抖音视频下载→Whisper转录→Qwen整理
- `新项目工作流程记录规范.md` — 新项目如何记录

## Skills（02_已装Skills）

- `可调用工具与技能总览.md` — 全部 Skills 速查（9个Meta-Skill + gstack套件）

## 维护规则

- 只有系统配置变更、Skill 安装、流程更新时才动这里
- 主人不需要看这个目录
- 三省六部规范已删除（2026-05-06）
