# 抖音视频转录流程 v2.0

> 更新日期: 2026-05-06
> 状态: ✅ 实测可用

## 系统架构

```
用户 → Hermes Agent → Douyin API (8088) → 下载视频 → ffmpeg → Whisper转录 → Qwen3-32B整理 → Obsidian
```

## 完整流程

```
┌─────────────────────────────────────────────┐
│ 1. 获取视频直链                              │
│    POST localhost:8088/api/douyin/web/fetch_one_video │
│    → aweme_id + msToken → 拿到 play_url     │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 2. 下载视频                                  │
│    requests.get(play_url, headers=HEADERS)  │
│    → .mp4 文件                               │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 3. ffmpeg 提音频                            │
│    ffmpeg -i video.mp4 -vn -acodec pcm_s16le │
│    -ar 16000 -ac 1 -y output.wav           │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 4. Whisper 转录                             │
│    Groq Whisper (gsk_lO...Tjpr)            │
│    → 文字稿                                  │
│    fallback: faster-whisper small (本地)    │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 5. Qwen3-32B 整理成结构化笔记               │
│    Groq LLM (qwen/qwen3-32b)               │
│    → Markdown 格式                           │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 6. 保存到 Obsidian                          │
│    E:\黑曜石\🤖 OpenClaw 工作区\抖音视频笔记\  │
└─────────────────────────────────────────────┘
```

## 单视频转录命令

```python
import requests, subprocess, openai, urllib.parse

API_BASE = "http://127.0.0.1:8088"
GROQ_KEY = "gsk_lO...Tjpr"  # 见 hushuo_transcribe_full.py

# 1. msToken
r = requests.get(f"{API_BASE}/api/douyin/web/generate_real_msToken", timeout=15)
ms_token = r.json()["data"]["msToken"]

# 2. 拿直链
aweme_id = "视频ID"
r = requests.get(f"{API_BASE}/api/douyin/web/fetch_one_video",
                  params={"aweme_id": aweme_id, "ms_token": ms_token}, timeout=20)
ad = r.json()["data"]["aweme_detail"]
url = urllib.parse.unquote(ad["video"]["play_addr"]["url_list"][0])

# 3. 下载
headers = {"User-Agent": "Mozilla/5.0", "Referer": "https://www.douyin.com/"}
resp = requests.get(url, headers=headers, stream=True, timeout=180)
with open("/tmp/video.mp4", "wb") as f:
    for chunk in resp.iter_content(8192): f.write(chunk)

# 4. 提音频
subprocess.run(["ffmpeg", "-y", "-loglevel", "error", "-i", "/tmp/video.mp4",
    "-vn", "-acodec", "pcm_s16le", "-ar", "16000", "-ac", "1", "/tmp/audio.wav"])

# 5. Whisper转录
client = openai.OpenAI(api_key=GROQ_KEY, base_url="https://api.groq.com/openai/v1")
with open("/tmp/audio.wav", "rb") as f:
    text = client.audio.transcriptions.create(
        model="whisper-large-v3-turbo", file=f, response_format="text"
    ).text
print(text)
```

## B站字幕（更快，零成本）

B站视频有官方字幕，直接拿不用转录：

```bash
# 用opencli（最快）
opencli bilibili captions <bvid>

# 示例：BV号获取后
opencli bilibili captions BV1M1421t7hT
```

结果秒出，0成本，优先用这个。

## 已知限制

1. **Groq Whisper免费额度**: 7200秒/小时，424条视频约7000秒，刚好在限额边缘
2. **Groq API Key**: 有时认证失败，用 `gsk_lO...Tjpr`（来自hushuo脚本），不要用config.yaml里的那个
3. **B站优先**: 有字幕的B站视频用opencli直接拿，不走Whisper流程
4. **抖音**: 必须下载→转录，没有直接字幕接口
