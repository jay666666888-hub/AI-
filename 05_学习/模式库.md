## 多平台内容采集转录流程

### 支持的平台

| 平台 | 采集方式 | 字幕/转录 | 优先方案 |
|------|---------|-----------|---------|
| **抖音** | 8088 API → 下载 | Whisper转录 | 优先B站同步版 |
| **B站(哔哩)** | opencli直拿字幕 | 直接用官方字幕 | ✅ 最快，零成本 |
| **小红书** | Chrome CDP (9222) | 暂无字幕，抓图文 | 文字内容提取 |
| **微博/知乎** | RSSHub / 热搜API | 暂无字幕 | 热搜API直连 |

### 优先策略

**有B站同步 → 用B站字幕（秒级，0成本）**
**没有B站 → 走抖音下载→Whisper转录**

```
用户给视频链接
       ↓
    是B站视频?
    ↙        ↘
   是          否 → 是抖音?
   ↓              ↙     ↘
 opencli拿字幕    是B站同步?    否
   ↓              ↙     ↘
  完成         是→B站字幕   否→下载+Whisper
   ↓                      ↓
整理→Obsidian      整理→Obsidian
```

## 抖音视频转录流程

### 系统架构

```
用户 → Agent → Douyin API (8088) → 下载视频 → ffmpeg → Whisper转录 → Qwen3-32B整理 → Obsidian
```

### 完整流程

1. **获取视频直链**
   - POST localhost:8088/api/douyin/web/fetch_one_video
   - → aweme_id + msToken → 拿到 play_url

2. **下载视频**
   - requests.get(play_url, headers=HEADERS)
   - → .mp4 文件

3. **ffmpeg 提音频**
   - `ffmpeg -i video.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 -y output.wav`

4. **Whisper 转录**
   - Groq Whisper (gsk_lO...Tjpr)
   - → 文字稿
   - fallback: faster-whisper small (本地)

5. **Qwen3-32B 整理成结构化笔记**
   - Groq LLM (qwen/qwen3-32b)
   - → Markdown 格式

6. **保存到 Obsidian**

### 快速执行脚本

```python
# 完整流程入口
python3 /home/admin1/hushuo_transcribe_full.py
# START_INDEX=0 从头跑，is_complete()自动跳过已有文件
```

## B站字幕采集（更快，零成本）

B站视频有官方字幕，直接拿不用转录：

```bash
# 用opencli（最快）
opencli bilibili captions <bvid>

# 示例：BV号获取后
opencli bilibili captions BV1M1421t7hT
```

结果秒出，0成本，优先用这个。

## 新项目工作流程规范

确保每个项目的工作流程都被正确记录，便于后续复用和自动化。

### 必须记录的内容

1. **项目概述**
   - 项目名称、开始日期、目标/目的、关键决策点

2. **技术方案**
   - 使用什么工具/技术、为什么选择这个方案、关键脚本和位置、遇到的问题和解决方案

3. **工作流程**
   - 完整的步骤流程、每个步骤的命令/脚本、输入和输出

4. **问题修复记录**
   - 遇到什么问题、尝试了什么解决方案，最终解决方案是什么

### 更新频率

- 项目开始时：创建初始文档
- 每完成一个阶段：更新进度
- 遇到问题时：记录问题和解决方案
- 项目完成时：最终版本

### 文件命名

```
项目名称_YYYY-MM-DD.md
```
